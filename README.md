# 아치 배치 플러그인

## 개요
텍스트 아이템을 아치 형태로 배치하는 이펙트입니다.

## 사용법
텍스트의 '문자별로 분할' 설정을 반드시 On으로 해주세요.

## 효과
### 높이
아치의 높이가 변합니다.

### 중심 위치
아치의 중심 위치(X)가 변합니다.

### 각도
아치의 중심을 향해 각도가 변합니다.

### 간격
텍스트 사이의 간격이 변합니다.
